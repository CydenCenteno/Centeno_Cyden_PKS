# Glossary

| Term | Meaning |
|------|---------|
| ACID | Atomicity, Consistency, Isolation, Durability — reliable DB transactions |
| API | Interface letting software talk to software |
| AAA | Authentication, Authorization, Accounting |
| Authentication | Prove who you are |
| Authorization | What you are allowed to do |
| CIA | Confidentiality, Integrity, Availability |
| CORS | Browser rule controlling cross-origin requests |
| CRUD | Create, Read, Update, Delete |
| CSRF | Attacker tricks logged-in user's browser into sending unwanted request |
| DBMS | Software managing databases (MySQL, PostgreSQL) |
| DNS | Translates domain names to IP addresses |
| DOM | Browser's tree representation of an HTML page |
| ERD | Entity Relationship Diagram |
| Hash | One-way fixed-length digest of data |
| HTTPS | HTTP over TLS (encrypted) |
| IDS/IPS | Intrusion Detection / Prevention System |
| JWT | JSON Web Token — signed token for stateless auth |
| MFA | Multi-factor authentication |
| Middleware | Software between applications/layers |
| MVC | Model-View-Controller pattern |
| ORM | Maps objects to database tables |
| OWASP | Org publishing top web security risks |
| REST | Architectural style for web APIs using HTTP |
| SIA | System Integration and Architecture |
| SQLi | SQL injection — attacker input alters query |
| TLS | Protocol encrypting network traffic |
| XSS | Cross-site scripting — attacker script runs in victim's browser |
